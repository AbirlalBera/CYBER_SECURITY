### DBMS :

Databases are usually controlled using a Database Management System (DBMS). Serving as an interface between the end user and the database, a DBMS is a software program that allows users to retrieve, update and manage the data being stored. Some examples of DBMSs include MySQL, MongoDB, Oracle Database and Maria DB.

### SQL :

The interaction between the end user and the database can be done using SQL (Structured Query Language). SQL is a programming language that can be used to query, define and manipulate the data stored in a relational database.

### Benefits of SQL and Relational Databases :

- **Fast:** Can process and retrieve large amounts of data quickly
- **Easy to Learn:** Uses plain English–like commands
- **Reliable:** Enforces strict data structures for accuracy
- **Flexible:** Supports powerful queries for data analysis

## Database Statements

##### **CREATE DATABASE** : 

The **CREATE DATABASE** statement is used to create a new database where data can be stored.

```sql
CREATE DATABASE database_name;
```

##### **SHOW DATABASES :**

The **SHOW DATABASES** statement displays a list of all databases available on the database server.

```sql
SHOW DATABASES;
```

##### **USE**

The **USE** statement selects a specific database as the active database so SQL commands apply to it.

```sql
USE database_name;
```

##### **DROP DATABASE**

The **DROP DATABASE** statement permanently deletes a database and all its data.

```sql
DROP DATABASE database_name;
```

## **Table Statements**

### CREATE TABLE

The **CREATE TABLE** statement is used to create a new table within an active database, defining its columns and data types.

`CREATE TABLE table_name (...);`

---

### SHOW TABLES

The **SHOW TABLES** statement lists all tables in the currently selected database.

`SHOW TABLES;`

---

### DESCRIBE (or DESC)

The **DESCRIBE** statement shows the structure of a table, including column names, data types, and constraints.

`DESCRIBE table_name;`

---

### ALTER TABLE

The **ALTER TABLE** statement modifies an existing table, such as adding, removing, or changing columns.

`ALTER TABLE table_name ADD column_name datatype;`

---

### DROP TABLE

The **DROP TABLE** statement permanently removes a table and all its data from the database.

`DROP TABLE table_name;`
