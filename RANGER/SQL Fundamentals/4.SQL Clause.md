A **clause** is a part of an SQL statement that defines **how data is filtered, grouped, or sorted**.

Common clauses include:

- `FROM` – specifies the table
    
- `WHERE` – filters rows before processing

---
**DISTINCT, GROUP BY, ORDER BY, HAVING**

## DISTINCT Clause :

The **DISTINCT** clause removes duplicate values and returns only **unique records**.

```
SELECT DISTINCT name FROM books;
```

## GROUP BY Clause :

The **GROUP BY** clause groups rows that have the same values and is often used with **aggregate functions** like `COUNT()`, `SUM()`, or `AVG()`.

```
SELECT name, COUNT(*) FROM books GROUP BY name;
```



### Result

- Books with the same name are grouped
- `COUNT(*)` shows how many times each book appears
---

## ORDER BY Clause

### Definition

The **ORDER BY** clause sorts query results in **ascending (ASC)** or **descending (DESC)** order.

---

### Ascending Order

`SELECT * FROM books ORDER BY published_date ASC;`

✔ Oldest to newest dates

---

### Descending Order

`SELECT * FROM books ORDER BY published_date DESC;`

✔ Newest to oldest dates

---

## HAVING Clause

### Definition

The **HAVING** clause filters **grouped results after aggregation**.  
Unlike `WHERE`, it works **after** `GROUP BY`.

### Example

`SELECT name, COUNT(*) FROM books GROUP BY name HAVING name LIKE '%Hack%';`

### Result

- Only book names containing **“Hack”**
    
- Shows grouped count for each match
    

---

## WHERE vs HAVING (Quick Comparison)

|Clause|Used When|Filters|
|---|---|---|
|WHERE|Before grouping|Individual rows|
|HAVING|After grouping|Aggregated results|
