## ==String Functions — Manipulating Text Data==

---
### `CONCAT()`

**Purpose:** Combine multiple strings or column values into one.

**Use case:** Creating readable output (reports, labels, messages).

```
SELECT CONCAT(name, ' is a ', category, ' book.') AS info FROM books;
```

![[Pasted image 20260122131710.png]]
✔ Useful for presentation  
✘ Not ideal for filtering or searching

---
### `GROUP_CONCAT()`

**Purpose:** Combine values from multiple rows into a single string.

**Use case:** Listing grouped data (e.g., books per category).

```
SELECT category, GROUP_CONCAT(name SEPARATOR ', ') AS books FROM books GROUP BY category;
```

![[Pasted image 20260122131824.png]]

✔ Great for summaries  
✔ Works with `GROUP BY`

---
### `SUBSTRING()`

**Purpose:** Extract part of a string.

**Use case:** Pulling years from dates, usernames from emails, etc.

```
SELECT SUBSTRING(published_date, 1, 4) AS year FROM books;
```

![[Pasted image 20260122131849.png]]

✔ Very common with dates and formatted strings

---
### `LENGTH()`

**Purpose:** Count characters in a string (including spaces).

**Use case:** Validation, limits, analytics.

```
SELECT LENGTH(name) AS name_length FROM books;
```

![[Pasted image 20260122131905.png]]

**As we can observe above, the query calculates the length of the string within the **name** column and stores it in a column named **name_length**.**

##  ==Aggregate Functions — Working with Multiple Rows==

---
### `COUNT()`

**Purpose:** Count rows.

```
SELECT COUNT(*) AS total_books FROM books;
```

![[Pasted image 20260122131924.png]]

✔ Most commonly used aggregate  
✔ Can be filtered with `WHERE`

---

### `SUM()`

**Purpose:** Add numeric values.

```
SELECT SUM(price) AS total_price FROM books;
```

![[Pasted image 20260122132009.png]]

✔ Only works on numeric columns  
✔ Ignores `NULL`

---

### `MAX()` and `MIN()`

**Purpose:** Find highest or lowest values.

```
SELECT MAX(published_date) AS latest_book FROM books;
```

![[Pasted image 20260122132030.png]]

```
SELECT MIN(published_date) AS earliest_book FROM books;
```

![[Pasted image 20260122132110.png]]
✔ Works on numbers, dates, and strings  
✔ Often used for time-based analysis
