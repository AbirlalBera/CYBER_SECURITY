**What is database?**




---
### Tables, Rows and Columns
### Table

A **table** is a structure in a relational database that stores related data in rows and columns.
### Row

A **row** is a single record in a table, representing one complete set of data.
### Column

A **column** is a field in a table that stores a specific type of data for all rows.
### Primary Key

A **primary key** is a column that uniquely identifies each record in a table and cannot contain duplicate or null values.
### Foreign Key

A **foreign key** is a column that creates a link between two tables by referencing the primary key of another table.
