**What is database?**
A **database** is an organised collection of structured data that is stored electronically and can be easily accessed, managed, updated, and analysed. Databases are widely used in everyday systems such as login authentication, social media platforms, and streaming services to store information like user details, posts, interactions, and viewing history. They are essential for both large organisations and small businesses to efficiently store and manage data.

### Table

A **table** is a structure in a relational database that stores related data in rows and columns.
### Row

A **row** is a single record in a table, representing one complete set of data.
### Column

A **column** is a field in a table that stores a specific type of data for all rows.
### Primary Key

A **primary key** is a column that uniquely identifies each record in a table and cannot contain duplicate or null values.
### Foreign Key

A **foreign key** is a column that creates a link between two tables by referencing the primary key of another table.
