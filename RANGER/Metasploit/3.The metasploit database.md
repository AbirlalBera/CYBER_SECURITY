Metasploit has a database function to simplify project management and avoid possible confusion when setting up parameter values.

first need to start the PostgreSQL database, which Metasploit will use with the following command: `
```
systemctl start postgresql
```

![[Pasted image 20260120212740.png]]

```
sudo -u postgres msfdb init
```

It initializes Metasploit’s database backend.

![[Pasted image 20260120220434.png]]

`sudo -u postgres msfdb delete` **completely removes Metasploit’s database**

Now launch `msfconsole` and check the database status using the `db_status` command.

```
msf6 > db_status
[*] Connected to msfdb. Connection type: postgresql.
```
