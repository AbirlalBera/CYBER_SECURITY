Msfvenom, which replaced Msfpayload and Msfencode, allows you to generate payloads.Msfvenom will allow you to access all payloads available in the  Metasploit framework. Msfvenom allows you to create payloads in many different formats (PHP, exe, dll, elf, etc.) and for many different target systems (Apple, Windows, Android, Linux, etc.).

```
msfvenom -l payloads    // Lists all payloads
```

**msfvenom output formats** let you generate payloads as executables (e.g., `.exe`) or raw code (e.g., PHP, Python). You can list supported formats with `msfvenom --list formats`.

### Encoders :

**Encoders** simply encode payloads (e.g., Base64) to change their appearance. They do **not reliably bypass antivirus**; they mainly help with formatting or basic evasion.with the ==`-e`== parameter

### **Handlers :**

**Handlers** are listeners in Metasploit that “catch” reverse shells or Meterpreter sessions generated by msfvenom payloads.

We will use Multi Handler to receive the incoming connection. The module can be used with the ==`use exploit/multi/handler`== command.Multi handler supports all Metasploit payloads and can be used for Meterpreter as well as regular shells.
