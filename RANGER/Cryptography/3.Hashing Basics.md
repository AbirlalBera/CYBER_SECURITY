
A **hash value** is a fixed-size string or characters that is computed by a hash function. A **hash function** takes an input of an arbitrary size and returns an output of fixed length, i.e., a hash value.


## Real-world example (Linux)

To verify a download:

```
sha256sum file.iso
```

Compare the output with the official SHA-256 hash published on the website.

# ==Hash Functions==

### What is a Hash Function?

A **hash function** is a one-way mathematical function that takes input data of any size and produces a fixed-size output called a **hash value**. It is designed so that the same input always produces the same output, small changes in input cause large changes in output, and it is computationally impractical to reverse the process or find two different inputs with the same hash.

### Why is Hashing Important?

**Hashing is important because it ensures data integrity and protects sensitive information without storing the original data.**

 **Integrity verification:** Hashing allows you to check whether data (files, downloads, messages) has been altered. If the hash changes, the data has changed.

**Password security:** Systems store **hashed passwords** instead of plaintext passwords, reducing damage if a database is compromised.

**Authentication:** Hashes are used to verify identities without revealing secrets.

**Efficiency:** Large data can be represented by a small fixed-size hash, making comparisons fast.

**Tamper detection:** Even a one-bit change produces a completely different hash, making unauthorized changes easy to detect.

### What’s a Hash Collision?

A **hash collision** occurs when **two different inputs produce the same hash output**.

### Why collisions are dangerous

If attackers can **intentionally create collisions**, they can:

- Bypass file integrity checks
- Forge digital signatures
- Replace trusted files with malicious ones

Shows the contents of `file2.txt` in hexadecimal and ASCII format.

```
hexdump -C  filename
```

Calculates the **MD5 hash** of all `.txt` files in the directory.
```
md5sum *.txt
```

Calculates the **SHA-1 hash** of all `.txt` files.
```
sha1sum *.txt
```

Calculates the **SHA-256 hash** of all `.txt` files.
```
sha256sum *.txt
```
